\begin{abstract}
When multiple AI agents share a physical memory store, they independently write facts about the same entities, creating \emph{cross-agent contradictions} that degrade downstream performance. We present a controlled benchmark with ground-truth labels (100 entities, 710 facts, 4 contradiction types), a comparative evaluation of four detection methods, and a causal analysis of resolution impact. Entity-level polarity clash detection achieves $F_1 = 0.813$ (precision 0.722, recall 0.929), significantly outperforming naive matching (McNemar $p = 0.039$) and rule-based explicit detection ($F_1 = 0.000$). Applied to a production system (26 days, 13 sources, 1{,}768 facts), the method identifies 198 polarity-clash candidates across 24{,}907 cross-source pairs, of which 11 are rule-classified as genuine temporal flips (0.044\%). Counterfactual analysis shows that supersession prevents 52--61\% of potential contradictions. In a downstream experiment ($n{=}100$), stale context causes a 39.0pp accuracy loss (McNemar $p < 0.0001$). An automatic temporal supersession algorithm resolves all detected contradictions on both datasets. Code, data, and scripts: \url{https://github.com/lanbass869-cell/cac-artifact}.
\end{abstract}


\section{Introduction}
Multi-agent AI systems accumulate persistent memory. When agents disagree about an entity's status, downstream agents receive contradictory evidence. This problem is unique to shared-memory architectures: single-tenant systems assign each user a separate space.

We address three questions:
\begin{enumerate}
\item \textbf{Detection}: How accurately can we detect contradictions? (Section~\ref{sec:eval}: $F_1 = 0.813$)
\item \textbf{Prevalence}: How common are contradictions in production? (Section~\ref{sec:production}: 0.044\%)
\item \textbf{Impact}: Does contradiction resolution improve downstream tasks? (Section~\ref{sec:downstream}: +39pp, $p < 0.0001$)
\end{enumerate}

\section{Related Work}
mem0~\\cite{mem0} and LangMem provide single-tenant memory; cross-agent contradictions cannot arise. Zep~\\cite{zep} offers temporal knowledge graphs. MemStrata~\\cite{memstrata} maintains bi-temporal validity. TOKI~\\cite{toki} formalizes conflict resolution. PoisonRecall~\\cite{poisonrecall} addresses malicious injection. FEVER~\\cite{fever} verifies claims against Wikipedia. No prior work combines a controlled benchmark, comparative evaluation, and causal analysis for agent memory contradictions.

\section{Detection Methods}
\label{sec:methods}

We compare four methods:

\subsection{Naive Polarity Matching}
Flags any cross-source pair where one fact contains positive and the other negative words, regardless of entity binding.

\subsection{Entity-Level Polarity Clash (Proposed)}
Extracts (entity, polarity) pairs from individual clauses using MemTether's \texttt{\_polarity\_by\_entity()}, then detects cross-source pairs with opposite polarity on the same entity. Requires identifier-like entities and excludes $>30$-fact entities.

\subsection{Rule-Based Explicit Detection}
Uses \texttt{detect\_explicit\_conflicts()} with closed status patterns and alias normalization.

\subsection{Temporal Supersession Algorithm}
Extends entity-level detection by recommending which fact to supersede based on temporal ordering and source trust. Returns \texttt{HUMAN\_REVIEW} when trust ordering is reversed.

\begin{proposition}[Soundness]
If two facts describe the same entity's status at different times, superseding the older fact eliminates the contradiction without losing information.
\end{proposition}

\begin{proof}
After supersession, only the newer fact remains active.
\end{proof}

\subsection{Statistical Significance}
McNemar's exact test comparing our method vs.\ naive matching: 7 discordant pairs (ours correct, naive wrong) vs.\ 2 (ours wrong, naive correct). One-sided $p = 0.039$, significant at 5\%.

\subsection{Error Analysis}
The 2 false negatives are entities where polarity is expressed via context rather than explicit status words. The 10 false positives are entity-name collisions where the extractor binds polarity to the wrong entity.

\begin{finding}[Low Production Contradiction Rate]
The 0.044\% rate is substantially lower than the 60\% observed for the single high-churn \emph{packy} entity. Contradictions concentrate in volatile configuration domains (API keys, tool versions) rather than being uniformly distributed.
\end{finding}

\subsection{Top Source Pairs}
The top three source pairs---(codex, workbuddy) 61, (workbuddy, workbuddy\_ai) 51, (codex, workbuddy\_ai) 38---account for 75.8\% of candidates. These are also the three most active sources (922, 521, 258 facts), suggesting contradiction density correlates with write volume.

\subsection{Verification Queries}
The following SQL queries reproduce each reported count:
\begin{verbatim}
-- Active facts
SELECT COUNT(*) FROM facts WHERE status='active';
-- Cross-source pairs
SELECT COUNT(*) FROM (
  SELECT fe1.fact_uid a, fe2.fact_uid b
  FROM fact_entities fe1
  JOIN fact_entities fe2
    ON fe1.entity_name=fe2.entity_name
    AND fe1.fact_uid < fe2.fact_uid
  JOIN facts f1 ON f1.uid=fe1.fact_uid
  JOIN facts f2 ON f2.uid=fe2.fact_uid
  WHERE f1.status='active' AND f2.status='active'
    AND f1.source != f2.source
  GROUP BY fe1.fact_uid, fe2.fact_uid
);
\end{verbatim}

\section{Downstream Impact}
\label{sec:downstream}

We sample 100 supersession events and construct two contexts per event: correct (new fact) and stale (old fact). An LLM (GLM-5.3-flash, temperature 0) answers ``What is the current status of [entity]?'' We grade correctness against the gold (new) fact.

\section{Discussion}
\subsection{Why Rule-Based Detection Fails}
\texttt{detect\_explicit\_conflicts()} achieves $F_1 = 0.000$ because it relies on closed Chinese status patterns with a predefined alias table. When entities have English names embedded in Chinese text, patterns fail to bind polarity to the correct entity.

\subsection{Practical Implications}
Entity-level polarity detection is the minimum viable approach for shared-memory contradiction detection. Combined with the temporal supersession algorithm, it provides an end-to-end detection-and-resolution path.

\subsection{Limitations}
\begin{itemize}
\item Benchmark: 100 entities is small for statistical generalization.
\item Single system: results reflect one production deployment.
\item Chinese lexicon: polarity words are Chinese; English-only deployments need adaptation.
\item Downstream: $n{=}100$ with one LLM judge.
\item Entity extraction: requires pre-built entity links.
\end{itemize}

\section{Conclusion}
We presented a controlled benchmark and comparative evaluation of cross-agent memory contradiction detection. Entity-level polarity clash achieves $F_1 = 0.813$ ($p = 0.039$ vs.\ naive), identifies 11 contradictions in 24{,}907 production pairs (0.044\%), and counterfactual analysis shows supersession prevents 52--61\% of potential contradictions. Stale context causes 39pp downstream accuracy loss ($p < 0.0001$). Code: \url{https://github.com/lanbass869-cell/cac-artifact}.
