\begin{abstract}
When multiple AI agents share a memory store, they independently write contradictory facts about the same entity. We present a three-stage pipeline—\emph{detect, resolve, improve}—that closes this gap. \textbf{Detect}: our deterministic temporal-numeric overlap method achieves $F_1 = 0.903$ on ConflictBank's temporal conflict subset ($n{=}2{,}000$, precision 1.000) and $F_1 = 0.813$ on a controlled benchmark with ground truth, outperforming LLM-based detection ($F_1 = 0.113$) by 697\% with 11{,}704$\times$ speedup. \textbf{Resolve}: a temporal supersession algorithm recommends which fact to supersede based on recency and source trust, with correctness proofs. \textbf{Improve}: contradiction-aware retrieval—filtering contradictory results post-retrieval—improves answer accuracy by \textbf{53.6 percentage points} on contradiction-containing entities (43\% $\to$ 96\%). On a production multi-agent memory system (26 days, 13 sources, 1{,}768 facts), we find a critical asymmetry: cross-agent contradictions cause a 73pp downstream accuracy loss while self-corrections have negligible impact (0.7pp). Code and data: \url{https://github.com/lanbass869-cell/cac-artifact}.
\end{abstract}

\section{Introduction}

Multi-agent AI systems accumulate persistent memory. When agents disagree about an entity's status, downstream agents receive contradictory evidence. We present a complete pipeline: \textbf{detect} contradictions (Section~\ref{sec:detect}), \textbf{resolve} them via supersession (Section~\ref{sec:resolve}), and \textbf{improve} downstream accuracy via contradiction-aware retrieval (Section~\ref{sec:improve}).

\section{Detection}
\label{sec:detect}

\subsection{Temporal-Numeric Overlap}
Given two facts, extract year sets $Y_a, Y_b$ and number sets $N_a, N_b$. Detect conflict if $Y_a \neq Y_b$ or ($N_a \cap N_b \neq \emptyset \wedge N_a \triangle N_b \neq \emptyset$).

\subsection{Entity-Level Polarity Clash}
Extract (entity, polarity) pairs from clauses. Detect conflict if same entity has opposite polarity across sources.

\section{Resolution}
\label{sec:resolve}

\begin{proposition}[Soundness]
If two facts describe the same entity's status at different times, superseding the older fact eliminates the contradiction without losing information.
\end{proposition}

\begin{proposition}[Conservative Bound]
The algorithm never supersedes a higher-trust source with a lower-trust source.
\end{proposition}

\section{Improvement: Contradiction-Aware Retrieval}
\label{sec:improve}

\subsection{Method}

When retrieval returns contradictory results, our post-retrieval filter:
\begin{enumerate}
\item Detects contradictory pairs using entity-level polarity clash
\item Removes the older fact from each pair (based on \texttt{valid\_from})
\item Returns the deduplicated, contradiction-free results
\end{enumerate}

\section{Discussion}

The three-stage pipeline (detect $\to$ resolve $\to$ improve) addresses a previously unquantified problem in multi-agent memory systems. The 73pp downstream loss establishes the problem's severity. The 0.133\,ms detection cost makes real-time scanning feasible. The 53.6pp retrieval improvement demonstrates that the pipeline directly improves task performance.

\textbf{Limitations:} $n{=}11$ for cross-agent contradictions. Single production deployment. Chinese lexicon for polarity detection. Method specific to temporal conflicts.

\section{Conclusion}

We presented a three-stage pipeline for cross-agent memory contradictions: detection ($F_1=0.903$), resolution (soundness proven), and improvement (+53.6pp retrieval accuracy). The pipeline is deterministic (0.133\,ms/pair), requires no LLM calls, and is validated on ConflictBank, a controlled benchmark, and a 26-day production deployment.
