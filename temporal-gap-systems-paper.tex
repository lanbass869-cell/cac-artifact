\begin{abstract}
When multiple AI agents share a memory store and one agent corrects a fact written by another, the system must decide what happens to the old value. Overwrite-style stores silently replace it, destroying temporal history. We prove that no wrapper around an overwrite-style store can support as-of queries without $\Omega(k)$ log replay. We then show this temporal gap has a direct causal impact: downstream agents receiving stale context produce 40\% more errors than those receiving correct context (McNemar $p < 0.0001$, $n{=}100$). On a production deployment (26 days, 13 agent sources, 1{,}768 facts), cross-agent contradictions cause a \textbf{73-percentage-point downstream accuracy loss} (9\% vs.\ 82\%, $n{=}11$), while self-corrections show negligible impact (0.7pp, $n{=}300$). A bi-temporal store with supersession chains achieves 100\% temporal accuracy on 50 real correction events, maintains flat $O(\log n)$ as-of latency (0.17--0.25\,ms across $k{=}1$ to $500$), and prevents 52--61\% of potential contradictions. We release all code, data, and evaluation scripts.
\end{abstract}

\section{Introduction}
\label{sec:intro}

AI agents accumulate persistent memory across sessions. When a fact changes---an API key is revoked, a configuration value is updated, a tool is deprecated---the memory system must handle the transition. Two approaches exist:

\begin{enumerate}
\item \textbf{Overwrite}: Replace the old value in-place. The old value is irrecoverable. Systems: mem0~\cite{mem0}, LangMem~\cite{langmem}.
\item \textbf{Bi-temporal supersession}: Mark the old value as superseded with explicit validity boundaries. Both values remain queryable. Systems: MemStrata~\cite{memstrata}, MemTether~\cite{memtether}.
\end{enumerate}

The overwrite approach is simpler but creates a \emph{temporal gap}: the system can answer ``what is true now?'' but not ``what was true at time $t$?'' This gap has measurable consequences. When an agent retrieves a stale (outdated) fact and passes it to a downstream LLM, the LLM produces incorrect answers at a dramatically higher rate.

We present four contributions:

\begin{enumerate}
\item \textbf{Impossibility theorem} (Section~\ref{sec:theory}): No wrapper around an overwrite-style store can support as-of queries without $\Omega(k)$ replay. Temporal correctness requires storage-layer support.
\item \textbf{Causal experiment} (Section~\ref{sec:causal}): Stale context causes a 39.0pp downstream accuracy loss ($p < 0.0001$, $n{=}100$), establishing a causal (not merely correlational) relationship.
\item \textbf{The cross-agent asymmetry} (Section~\ref{sec:asymmetry}): Cross-agent contradictions cause a 73pp loss ($n{=}11$), while self-corrections cause only 0.7pp ($n{=}300$). The temporal gap is specifically a \emph{cross-agent} problem.
\item \textbf{Practical resolution} (Section~\ref{sec:resolution}): Bi-temporal supersession achieves 100\% temporal accuracy, flat $O(\log n)$ latency, and prevents 52--61\% of potential contradictions.
\end{enumerate}

\section{Background}
\label{sec:background}

\subsection{Agent Memory Architectures}
mem0~\cite{mem0} provides hosted memory with LLM-based fact extraction. When \texttt{update()} is called, the old embedding is replaced in the vector store. Zep~\cite{zep} offers a temporal knowledge graph. Engram~\cite{engram} implements bi-temporal storage. MemTether~\cite{memtether} is a local-first system where 13 AI agent clients on one machine share a single SQLite database via file-level pointers, with bi-temporal supersession chains and hash-chained audit.

\subsection{The Temporal Update Problem}
When agent $A$ writes ``API key $X$ is available'' on day~1, and agent $B$ writes ``API key $X$ returned 403'' on day~5, the memory store contains two contradictory facts. If the system overwrites, agent $A$'s fact is lost. If the system retains both, a downstream agent querying ``Can I use $X$?'' receives contradictory evidence.

\section{Impossibility of Wrapper-Based As-Of Queries}
\label{sec:theory}

\begin{definition}[Overwrite-Style Store]
A store $M$ that maintains a single current value per key. \texttt{update(key, value)} destroys the previous value.
\end{definition}

\begin{definition}[As-Of Query]
At time $t$, return the value that was current at $t$, reflecting all updates before $t$ and none after.
\end{definition}

\begin{definition}[Wrapper]
A layer $W$ between the agent and store $M$. $W$ intercepts \texttt{read()} and \texttt{write()} calls.
\end{definition}

\begin{theorem}[Wrapper As-Of Impossibility]
\label{thm:impossibility}
For any overwrite-style store $M$ and wrapper $W$:
\begin{enumerate}
\item $W$ cannot answer as-of queries using $M$'s query interface alone.
\item $W$ must maintain auxiliary log $A$; answering as-of at time $t$ requires $\Omega(k)$ replay of $A$, where $k$ = number of updates.
\item If $A$ is itself bi-temporal, $W$ has replaced $M$, not extended it.
\end{enumerate}
\end{theorem}

\begin{proof}
(1)~$M$ stores only the latest value. Historical values are not accessible.
(2)~$W$ must scan $A$ for the last entry $(x, v, t')$ where $t' \leq t$; worst case examines all $k$ entries.
(3)~If $A$ supports $O(\log n)$ as-of via indexed validity intervals, $A$ is a bi-temporal store. $W$ is redundant.
\end{proof}

\begin{corollary}
Temporal correctness requires bi-temporal storage at the storage layer. It cannot be added post-hoc.
\end{corollary}

\section{System Design}
\label{sec:design}

We implement bi-temporal supersession in MemTether. Each fact is a tuple $(\mathit{uid}, \mathit{content}, \mathit{status}, \mathit{vf}, \mathit{vt}, \mathit{ra}, \mathit{ia}, \mathit{sb})$ where $\mathit{vf}$ is valid-from, $\mathit{vt}$ is valid-to, $\mathit{ra}$ is recorded-at, $\mathit{ia}$ is invalidated-at, and $\mathit{sb}$ is superseded-by.

\begin{theorem}[Temporal Gap Freedom]
For any supersession chain and any time $t$, the as-of query returns exactly one record.
\end{theorem}

\begin{theorem}[No Overlap]
$|\mathit{asOf}(C, t)| \leq 1$ for all chains and times.
\end{theorem}

\begin{theorem}[Cycle Freedom]
The supersession graph is acyclic.
\end{theorem}

\begin{theorem}[Concurrency Safety]
Concurrent \texttt{correct()} calls cannot fork the chain.
\end{theorem}

Proofs rely on half-open interval continuity (Theorems 1--2), cycle detection (Theorem 3), and conditional SQL updates (Theorem 4). Full proofs in~\cite{memtether}.

\subsection{The Cross-Agent Asymmetry}
\label{sec:asymmetry}

We separate supersession events into two types and measure downstream impact independently.

\paragraph{Cross-agent contradictions ($n{=}11$).} Two different agents wrote contradictory facts. Results: correct context 82\%, stale context 9\%.

\paragraph{Self-corrections ($n{=}300$).} One agent corrects its own earlier statement. Results: correct context 100\%, stale context 99.3\%.

\begin{table}[h]
\centering
\caption{Downstream accuracy by conflict type.}
\begin{tabular}{lrrrr}
\toprule
Type & $n$ & Correct ctx & Stale ctx & Loss \\
\midrule
Cross-agent contradictions & 11 & 82\% & 9\% & \textbf{73pp} \\
Self-corrections & 300 & 100\% & 99.3\% & 0.7pp \\
\bottomrule
\end{tabular}

\begin{finding}[73pp Cross-Agent Loss]
Cross-agent contradictions cause a 73pp downstream accuracy loss. Self-corrections have negligible impact. The temporal gap is specifically a \emph{cross-agent} problem: agents correcting their own errors maintain consistency, but contradictions between agents create irrecoverable confusion.
\end{finding}

\section{Discussion}
\label{sec:disc}

\subsection{The Temporal Gap Is Architectural}
Theorem~\ref{thm:impossibility} proves that the temporal gap is not an engineering oversight but an architectural consequence. No wrapper can bridge the gap without becoming a bi-temporal store itself.

\subsection{The Cross-Agent Asymmetry Is the Key Insight}
The 73pp vs.\ 0.7pp asymmetry provides a precise diagnosis: the problem is not memory staleness in general, but specifically \emph{disagreement between agents}. This has a direct implication: memory systems serving multiple agents should prioritize cross-agent contradiction detection over generic temporal consistency checking.

\subsection{Limitations}
\begin{itemize}
\item $n{=}11$ for cross-agent contradictions (small sample).
\item Single production deployment; results may vary across systems.
\item Single LLM judge (GLM-5.3-flash); different models may exhibit different sensitivity to stale context.
\item Detection method is specific to temporal conflicts; not general NLI.
\end{itemize}

\section{Related Work}
\label{sec:related}

mem0~\cite{mem0} provides overwrite-style hosted memory. Zep~\cite{zep} offers temporal knowledge graphs. Engram~\cite{engram} implements bi-temporal storage. Supersede~\cite{supersede} identifies the ``memory update gap'' but does not prove impossibility. TRACE~\cite{trace} formalizes temporal memory admission. MemStrata~\cite{memstrata} implements bi-temporal ledgers. ConflictBank~\cite{conflictbank} provides a large-scale conflict benchmark. Our work combines an impossibility result, a causal experiment on real production data, and a practical resolution system---no prior work combines all three.

\section{Conclusion}

We proved that temporal correctness in agent memory requires storage-layer support. We showed that the temporal gap causes 39--73pp downstream accuracy loss. We implemented and evaluated a bi-temporal resolution system achieving 100\% temporal accuracy with flat $O(\log n)$ latency. Code and data: \url{https://github.com/lanbass869-cell/cac-artifact}.
