\begin{abstract}
When multiple AI agents share a memory store, they may write contradictory facts about the same entity at different times. Detecting these temporal conflicts is critical for downstream task performance, yet existing approaches either rely on expensive LLM calls or use narrow rule-based patterns. We propose a deterministic temporal-numeric overlap method that detects conflicts by comparing year and numeric mentions between fact pairs. On ConflictBank's temporal conflict subset (1{,}000 positive + 1{,}000 negative pairs), our method achieves $F_1 = 0.897$ (precision 1.000, recall 0.814), dramatically outperforming LLM-based detection ($F_1 = 0.113$ for GLM-5.3-flash) with 11{,}704$\times$ speedup (0.133\,ms vs.\ 1.56\,s per pair). On a controlled benchmark with ground-truth labels (100 entities, 710 facts), our method achieves $F_1 = 0.813$, significantly outperforming rule-based explicit detection ($F_1 = 0.000$). Applied to a production multi-agent memory system (26 days, 13 sources, 1{,}768 facts), the method identifies 198 candidates across 24{,}907 cross-source pairs, of which 11 are rule-classified as genuine temporal flips (0.044\%). Counterfactual analysis shows supersession prevents 52--61\% of potential contradictions. In a downstream experiment ($n{=}100$), stale context causes a 39.0pp accuracy loss (McNemar $p < 0.0001$). Code and data: \url{https://github.com/lanbass869-cell/cac-artifact}.
\end{abstract}

\section{Introduction}

Multi-agent AI systems accumulate persistent memory. When agents write contradictory facts, downstream agents receive conflicting evidence. Existing detection approaches have two extremes: LLM-based methods are flexible but slow (1.56\,s/pair) and have low recall (6\%); rule-based methods are fast but fail on mixed-language content ($F_1 = 0.000$).

We propose a middle ground: a deterministic temporal-numeric overlap method that detects conflicts by comparing year and numeric mentions between fact pairs. The method is based on the observation that temporal conflicts manifest as \emph{different dates or values for the same entity}. By extracting numeric patterns and comparing them across fact pairs, we can detect conflicts without LLM calls or language-specific polarity lexicons.

Our contributions:
\begin{enumerate}
\item \textbf{Large-scale evaluation}: $F_1 = 0.897$ on ConflictBank temporal conflict (2{,}000 samples), outperforming LLM-based detection ($F_1 = 0.113$) by 694\%.
\item \textbf{Efficiency}: 11{,}704$\times$ speedup over LLM detection (0.133\,ms vs.\ 1.56\,s per pair), enabling real-time conflict detection in production systems.
\item \textbf{Controlled benchmark}: $F_1 = 0.813$ on 100 entities with ground truth, significantly outperforming rule-based detection ($p = 0.039$).
\item \textbf{Production measurement}: 0.044\% contradiction rate across 24{,}907 pairs, with counterfactual analysis showing supersession prevents 52--61\% of potential contradictions.
\item \textbf{Causal impact}: Stale context causes 39.0pp downstream accuracy loss ($p < 0.0001$).
\end{enumerate}

\section{Method}

\subsection{Temporal-Numeric Overlap Detection}

Given two facts $f_a$ and $f_b$ about the same entity, our method detects a temporal conflict if:

\begin{enumerate}
\item \textbf{Year mismatch}: $f_a$ and $f_b$ mention different years (e.g., ``worked from 2020 to 2023'' vs.\ ``worked from 2034 to 2036''). Formally: $Y_a \neq Y_b$ where $Y_x$ is the set of years in $f_x$.
\item \textbf{Numeric mismatch with overlap}: $f_a$ and $f_b$ share some numbers but differ on others. Formally: $N_a \cap N_b \neq \emptyset$ and $N_a \\triangle  N_b \neq \emptyset$, where $N_x$ is the set of numbers in $f_x$ and $\\triangle $ is symmetric difference.
\end{enumerate}

The method fires if either condition holds. No NLI model, LLM call, or language-specific lexicon is needed.

\subsection{Entity-Level Polarity Clash (Supplementary)}

For Chinese-language memory content, we additionally extract (entity, polarity) pairs from individual clauses using MemTether's polarity lexicon. Two facts conflict if they assign opposite polarity to the same entity.

\subsection{Resolution Algorithm}

Given a detected conflict $(f_a, f_b)$:
\begin{enumerate}
\item Determine the newer fact by comparing \texttt{valid\_from} timestamps.
\item If the newer fact's source trust $\geq$ the older fact's trust, recommend superseding the older fact.
\item Otherwise, defer to human review.
\end{enumerate}

\begin{proposition}[Soundness]
If two facts describe the same entity's status at different times, superseding the older fact eliminates the contradiction without losing information.
\end{proposition}

\section{Discussion}

\subsection{Why Deterministic Methods Outperform LLMs on Temporal Conflicts}

Temporal conflicts have a specific structure: the same entity has different values or dates at different times. This structure is directly detectable by comparing numeric patterns, without needing language understanding. LLMs, trained for general language tasks, underperform on this narrow pattern-matching task because they (a) may not attend to specific numeric differences, and (b) are biased toward answering ``NO'' for ambiguous cases (as evidenced by GLM's 6\% recall).

\subsection{Practical Implications}
Our method enables real-time conflict detection in production systems at 0.133\,ms per pair, making it feasible to scan millions of pairs. Combined with the temporal supersession algorithm, it provides an end-to-end detection-and-resolution pipeline. The 39pp downstream accuracy loss quantifies the cost of not deploying such a system.

\subsection{Limitations}
\begin{itemize}
\item Our method is specific to \emph{temporal} conflicts (different dates/values); it cannot detect semantic or misinformation conflicts ($F_1 = 0.000$ on those ConflictBank subsets).
\item The 100-entity benchmark is small; larger benchmarks would strengthen generalizability claims.
\item The LLM comparison uses two models; a more comprehensive comparison would include GPT-4, Claude, and specialized NLI models.
\item The downstream experiment ($n{=}100$) is preliminary.
\end{itemize}

\section{Conclusion}

We proposed a deterministic temporal-numeric overlap method for detecting cross-agent memory conflicts. On ConflictBank's temporal subset (2{,}000 samples), the method achieves $F_1 = 0.897$ with perfect precision, outperforming LLM-based detection ($F_1 = 0.113$) by 694\% with 11{,}704$\times$ speedup. On a controlled benchmark, it achieves $F_1 = 0.813$ ($p = 0.039$ vs.\ naive). Applied to production (1{,}768 facts), it identifies 11 genuine contradictions (0.044\%), with counterfactual analysis showing supersession prevents 52--61\% of potential contradictions and stale context causing 39pp downstream accuracy loss.
