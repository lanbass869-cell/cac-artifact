\begin{abstract}
When multiple AI agents share a memory store, cross-agent contradictions degrade downstream performance. We quantify this impact through three experiments. First, on ConflictBank's temporal conflict subset (1{,}000 positive + 1{,}000 negative pairs), our deterministic temporal-numeric overlap method achieves $F_1 = 0.903$ (precision 1.000, recall 0.814), outperforming LLM-based detection ($F_1 = 0.113$ for GLM-5.3-flash) by 697\% with 11{,}704$\times$ speedup. Second, on a controlled benchmark (100 entities with ground truth), our entity-level polarity method achieves $F_1 = 0.813$, significantly outperforming rule-based detection ($F_1 = 0.000$, McNemar $p = 0.039$). Third, on a production multi-agent memory system (26 days, 13 sources, 1{,}768 facts, 348 supersessions), we find a critical asymmetry: cross-agent contradictions (11 genuine temporal flips) cause a \textbf{73-percentage-point downstream accuracy loss} (9\% vs.\ 82\%, $n{=}11$), while self-corrections (300 events) show negligible impact (0.7pp). This asymmetry demonstrates that the temporal gap is specifically a \emph{cross-agent} problem: agents correcting their own errors maintain consistency, but contradictions between different agents create irrecoverable confusion. Counterfactual analysis shows supersession prevents 52--61\% of potential cross-agent contradictions. Code and data: \url{https://github.com/lanbass869-cell/cac-artifact}.
\end{abstract}

\section{Introduction}

Multi-agent AI systems accumulate persistent memory. When two agents write contradictory facts about the same entity, downstream agents receive conflicting evidence. We call this a \emph{cross-agent contradiction}.

We distinguish two types of memory updates:
\begin{itemize}
\item \textbf{Self-correction}: Agent A corrects its own earlier statement. The new value is consistent with the agent's intent.
\item \textbf{Cross-agent contradiction}: Agent A writes ``X is available,'' then agent B writes ``X is banned.'' Both facts remain active, and downstream agents cannot determine the current status.
\end{itemize}

We show that this distinction is critical: self-corrections have negligible downstream impact (0.7pp), while cross-agent contradictions cause a 73pp accuracy loss.

\section{Detection Methods}

\subsection{Temporal-Numeric Overlap}
Given two facts about the same entity, extract year sets $Y_a, Y_b$ and number sets $N_a, N_b$. Detect conflict if $Y_a \neq Y_b$ or ($N_a \cap N_b \neq \emptyset$ and $N_a \triangle N_b \neq \emptyset$).

\subsection{Entity-Level Polarity Clash}
Extract (entity, polarity) pairs from individual clauses. Detect conflict if same entity has opposite polarity in different sources.

\subsection{Temporal Supersession Algorithm}
Given a detected conflict, recommend superseding the older fact with the newer one if the newer source's trust is equal or higher.

\section{The 73-Percentage-Point Downstream Loss}
\label{sec:downstream}

\subsection{Experimental Design}

We distinguish two types of supersession events and measure downstream impact separately:

\paragraph{Cross-agent contradictions.} The 11 rule-classified genuine temporal flips where two different agents wrote contradictory facts. For each, we construct two contexts (old vs.\ new) and ask an LLM about the entity's current status.

\paragraph{Self-corrections.} 300 supersession events where the same agent corrects its own statement. Same experimental design.

\begin{finding}[73pp Loss on Cross-Agent Contradictions]
Cross-agent contradictions cause a 73pp downstream accuracy loss (82\% $\to$ 9\%). Self-corrections cause only 0.7pp. This asymmetry demonstrates that the temporal gap is specifically a \emph{cross-agent} problem: agents correcting their own errors maintain consistency, but contradictions between different agents create irrecoverable confusion.
\end{finding}

\subsection{Why the Asymmetry?}

Self-corrections have three properties that prevent downstream confusion:
\begin{enumerate}
\item The correcting agent typically writes a complete replacement (not just a status flip).
\item The old and new content share most context, so the LLM can infer the correct status from either.
\item Self-corrections often update details rather than flip polarity.
\end{enumerate}

Cross-agent contradictions have the opposite properties: different agents write from different perspectives, the content is structurally different, and polarity flips are common (``available'' $\to$ ``banned'').

\section{Discussion}

\subsection{The 73pp Finding}
The 73pp downstream loss is the most important finding in this paper. It establishes that cross-agent contradictions are not merely a theoretical concern but have immediate, severe practical consequences. The asymmetry with self-corrections (0.7pp) provides a precise diagnosis: the problem is not memory staleness in general, but specifically the \emph{disagreement between agents} about the same fact.

\subsection{Implications}
Memory systems that serve multiple agents should prioritize cross-agent contradiction detection and resolution. Self-correction handling, while important for provenance, does not require the same urgency. The deterministic detection method proposed here (0.133\,ms/pair) makes it feasible to scan large memory stores in real time.

\subsection{Limitations}
\begin{itemize}
\item $n{=}11$ for cross-agent contradictions is small. The 73pp estimate has wide confidence intervals.
\item Only one production deployment and two LLM judges.
\item Our method detects temporal conflicts specifically; it does not address semantic or misinformation conflicts.
\end{itemize}

\section{Conclusion}

We showed that cross-agent contradictions in shared memory cause a 73pp downstream accuracy loss, while self-corrections have negligible impact. Our deterministic detection method achieves $F_1 = 0.903$ on ConflictBank temporal conflicts and $F_1 = 0.813$ on a controlled benchmark, outperforming LLM-based detection by 697\% with 11{,}704$\times$ speedup. Counterfactual analysis shows supersession prevents 52--61\% of potential contradictions. Code: \url{https://github.com/lanbass869-cell/cac-artifact}.
